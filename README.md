## ◌ About

A collection of **simple, polished, and reusable README templates** for GitHub projects.

Whether you're building a small experiment, a school project, a portfolio, a library, or an open-source project, start with a structure that already looks good.

> Good software deserves good documentation.

## ⌘ How to Use

### 1. Choose a template

Find a template that matches your project.

### 2. Copy it

Open the template and copy its contents into your project's `README.md`.

### 3. Customize it

Replace the placeholders, remove sections you don't need, and make it yours.

```text
Template
   ↓
Customize
   ↓
Your README
   ↓
Better repository
```

## ◌ Design Principles

These templates are intentionally built around a few principles:

| Principle           | Meaning                                      |
| :------------------ | :------------------------------------------- |
| **Clarity**         | Readers should understand a project quickly. |
| **Simplicity**      | Remove sections that don't provide value.    |
| **Consistency**     | Use predictable structures across projects.  |
| **Practicality**    | Every section should have a purpose.         |
| **Customizability** | Templates should be easy to adapt.           |

The goal isn't to make every README identical.

The goal is to give you a **good starting point**.
